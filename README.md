# AKIF-SE
demo repository
This is our first lab of the Software Engineering. The lab task is configure the Git account with Git Bash and then create and clone the repository to the local device file named “SE”. After that a file should be created automatically under the “SE” file and the file name will be same as the repository name. Then we have to perform some Git commands through Git Bash to update/push the file also create new branch and branch shifting.
